# Third-party licenses

This directory is included with the published application, ZIP, and installer.

- `THIRD-PARTY-NOTICES.txt`: licenses of JavaScript packages bundled into `WebAssets` (generated by `tools/web-assets/generate-notices.mjs`).
- `KaTeX-LICENSE.txt`: KaTeX stylesheet notice and SIL Open Font License 1.1 for its fonts. A copy is placed beside fonts in generated HTML when math or Mermaid is used.
- `PDFsharp-LICENSE.txt`: PDFsharp notice and MIT license text.
- `NuGet-PACKAGES.md`: resolved application and test NuGet dependency inventory.
- `NuGet/`: license texts for application NuGet dependencies whose text is supplied by the package or differs from MIT, plus the common MIT terms and copyright notices.

The Markdown.ColorCode and WebView2 license files were copied from their resolved NuGet packages. The Markdig, UTF.Unknown, and AngleSharp.Css texts were taken from the upstream commits recorded in their package metadata: [Markdig 1.3.2](https://github.com/xoofx/markdig/blob/fc705234fa211d179ee1d5e7656b51ab99f70ca9/license.txt), [UTF.Unknown 2.7.0](https://github.com/CharsetDetector/UTF-unknown/blob/fd4c6fab634ef3783f8b5cb88e9ae9b2cc295ad5/license/MPL-1.1.txt), and [AngleSharp.Css 1.0.2](https://github.com/AngleSharp/AngleSharp.Css/blob/d158478f58882dad1d595dc7bb2286f3da4bf6ea/LICENSE).

The root `LICENSE` is the license for MarkdownExporter itself. It remains at the repository root for GitHub and is copied as `Licence/MarkdownExporter-LICENSE.txt` when the application is published. Refresh the inventory and notices when NuGet or bundled web asset versions change.
